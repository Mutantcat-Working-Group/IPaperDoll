### 一、产品概述

- 安卓手机上的纸娃娃软件，用来生成游戏素材与人物行走图。
- 可自行导入素材进行纸娃娃合成，玩法与 PC 版纸娃娃软件（含 RPG 引擎内置编辑器）一致。
- 简单点击即可操作，兼容网络常见的 128*192 像素、以及同比例缩放的 4*4 规格纸娃娃行走图素材。
- 部件随意混搭，一键保存成品。

核心价值：把纸娃娃合成搬进口袋，随时随地把素材拼成可用的人物行走图。

### 三、功能说明

#### 添加素材

- 把素材文件放到手机存储根目录的「纸娃娃哎」文件夹下的对应目录即可（注意 A1 是输出文件列表）。

#### 功能使用

- 点击清除会取消当前所有选项，请谨慎点击。
- 点击随机会从已有素材中随机组合一套。
- 点击构建会在本地生成成果文件，输出到手机存储根目录「纸娃娃哎」文件夹下的 A1 文件夹。
- 点击预览可查看当前生成的上一组人物行走图。

### 四、安装与下载

最新版本：`1.0.20260920`

从 [Releases](https://github.com/Mutantcat-Working-Group/IPaperDoll/releases) 下载 `app-release.apk` 直接安装，另附 `SHA256SUMS` 供校验。版本号使用纯日期递增（如 `1.0.20260920`），推送同族标签（`v` 前缀可选）后，GitHub Actions 会自动构建 Release APK 并发布 Release。

### 五、快速上手

1. 安装 APK 并打开应用。
2. 在手机存储根目录的「纸娃娃哎」文件夹中放入纸娃娃素材（注意 A1 为输出目录）。
3. 进入纸娃娃界面点选部件进行混搭，或点随机快速组合。
4. 点击构建生成行走图，在 A1 文件夹查看成品；点预览回看上一组。
